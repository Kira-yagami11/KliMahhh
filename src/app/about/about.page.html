A little context

This application was developed as an academic project for the Mobile Application Development course. It provides weather forecasts and local weather information for selected areas in Nueva Ecija. Forecasts are model-based and may differ from actual weather conditions. This application is not an official PAGASA service and should not be used as a substitute for official weather advisories and emergency warnings.
